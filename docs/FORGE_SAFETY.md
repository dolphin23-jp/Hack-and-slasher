# 鍛冶と自動分解

## 合成

鍛冶対象を選択 →「同系統・同階級を合成」→ 素材を選択 → 消費内容を確認 → 確定。

候補一覧は6個ずつ表示し、レアリティ・階級・Tier・強化値・最高Affixロール・獲得合成進行を比較できる。選択した素材の全性能と、対象の合成進行の増加量を確定前に表示する。最低レアリティの自動選択は廃止。

確認時の対象・素材を複製して保持し、確定時に実物と照合する。並べ替えによるインデックス変更では対象がずれない。保護設定、性能、鍛冶対象が変わった場合、素材が保管庫などへ移動した場合、同じIDが複数ある場合は消費せず再確認を求める。ロック・お気に入りは候補外。二重確定は無効。

## 自動分解

装備画面の「自動分解ルール」から設定する。設定は次に拾う装備に適用し、所持品を遡って分解しない。

| 条件 | 初期値 | 選択肢 |
| --- | --- | --- |
| 有効・無効 | OFF（旧ONは維持） | ON / OFF |
| レアリティ上限 | Rare | Common / Rare |
| 最高ロール | 70%未満 | 50% / 70% / 90%未満 / 条件なし |
| Tier上限 | T2 | T1〜T5 |
| 階級上限 | 2 | 1〜6 |
| 残す武器 | 指定なし | 指定なし / 7系統のいずれか |

すべての条件を満たす時だけ分解する。ロック・お気に入り・Epic以上は常に除外。最高ロールはAffixごとの抽選範囲内の品質を計算し、その最大値を採用する。99%のAffixが1つあれば他のAffixが低品質でも保持する。Affixのない品は基本性能で判定し、範囲不明・固定値の旧品は100%として扱う。「条件なし」を選ぶとこの品質制限を解除する。

70%ちょうどなどの境界は浮動小数点の誤差を考慮して保持する。旧設定のON/OFFは保持し、新規の条件は上記の保守的な初期値で補う。設定はセーブをまたいで保持。

## 一括分解

従来の「Rare以下/ジャンク分解」を「ジャンク一括分解」へ変更。ジャンク指定した未保護品だけを8個ずつ確認でき、総数と獲得素材も表示する。確定前に全対象を照合し、1個でも変更・移動・保護されていたら全処理を中止する。ジャンク指定していない良品を、レアリティだけで巻き込まない。

`ForgeScreen`、`SalvageScreen`、`SalvagePolicy` に分離。`forge_runner.gd` では実際のInventory・拾得・セーブファイルを使い、対象照合、境界、品質、保存互換、キャンセルを検証する。画面検証ではiPad比率で素材選択、確認、確定、自動分解設定、ジャンク分解を操作する。

階級進化のAffix継承仕様は、この更新では変更していない。
