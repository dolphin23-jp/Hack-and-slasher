# Skill 2.0 — 三武器とスキルの統合

`dc8b0fc` の depth pass を土台に、優先度1・2（スキル統合とRecipe拡張）を実装。

## 操作

| 入力 | 動作 | 再使用 |
| --- | --- | --- |
| Q / RMB / Y | 現在表示中の武器のWeapon Art。未攻撃時は第1武器 | 武器別4〜5秒、CDR適用 |
| E / LB | 第1→第2→第3武器の技を0.16秒間隔で発動 | 10秒、CDR適用 |
| R / RB | 強化した三器連携。通常攻撃の3連続命中を4回で使用可能 | ゲージ全消費、短い再発動防止CT |

既存のタッチ用3ボタンも同じ動作。Qのアイコンと技名は現在武器に連動し、Rに蓄積数とREADYを表示。HUDの【武器】は次の通常攻撃、Q表示は現在の武器を指す。

| 武器 | 技 | 性質 |
| --- | --- | --- |
| 剣 | 瞬歩斬 | 衝突判定付き踏み込みから扇状斬撃 |
| 鎌 | 渦刈り | 周囲の敵を吸引し全周攻撃 |
| 槍 | 天穿ち | 高速・長射程・大貫通 |
| 杖 | 魔力砲 | 太い貫通魔弾、T4以上で反射 |
| 籠手 | 百裂拳 | 短射程4連打と残像 |
| メイス | 地砕波 | 全周衝撃波と強いノックバック |
| 魔刃 | 幻刃連波 | 斬撃＋魔撃の波動3本 |

連携技は発動時点の装備・基礎威力・方向・中心位置を固定。鎌→杖→槍なら吸引→魔力砲→貫通になる。発動中も移動・通常攻撃・回避可能。連携途中の装備交換で後段の武器が変わることはない。技の予約はプレイ中だけ進み、死亡時に中止。

## Recipe

| 接続 | 名前 | 通常攻撃への効果 |
| --- | --- | --- |
| 斬→打 | 断甲 | 威力+10%、ノックバック+45% |
| 打→貫 | 破砕貫通 | 威力+18% |
| 魔→斬 | 魔力纏刃 | 威力+15%、範囲+8% |
| 鎌→杖 | 収束魔撃 | 威力+12%、射程+18% |
| 貫→魔 | 穿孔追魔 | 貫撃が実際に命中した近くの敵を追尾 |
| 打→斬 | 崩し薙ぎ | 範囲+22% |
| 斬→貫 | 裂傷貫通 | 斬撃の痕が残る敵へ追加+25% |
| 杖→鎌 | 魔痕収穫 | 魔撃の痕が残る敵を吸引 |
| 籠手→籠手 | 連拳加速 | 攻撃速度×1.22 |
| メイス→杖 | 震源魔撃 | 直前のメイス命中地点に40%威力の爆発 |

痕は1.5秒。壁越しの追尾・吸引・爆発は不可。魔刃は両方の属性で前後の接続を判定する。複数Recipeの威力・範囲などの倍率は各項目の最大値を採用し、乗算で暴走させない。三相連環は「3つの攻撃に異なる属性を1つずつ割り当てられるか」で判定する。魔刃1本の2属性だけでは三相にならない。

## 蓄積と互換

- 連続した通常攻撃3回が、それぞれ敵に命中して初めて1蓄積。空振り・多段・Mythicの複数弾で水増ししない。
- 通常攻撃の遠隔弾は、発射した攻撃番号へ命中を帰属。遅れて命中しても同じ3連を重複計上しない。スキル弾・二次爆発はゲージを増やさない。
- 装備交換・武器並べ替えは進行中の通常攻撃連携を解除。獲得済みのゲージは保持。
- ゲージとスキルCTは保存・復元。旧セーブの未保存フィールドは0として扱う。途中の予約技や未完成の3連は復帰時に再生しない。
- 旧ランス分岐・ノヴァ祝福は `migrate_upgrades` により武技威力、連携威力、奥義威力、連携範囲、残響へ移行。旧キーを削除するため二重加算しない。
- 旧槍の巡礼は「第1武器が槍、武技威力+18%、攻撃速度-10%」へ更新。
- 旧レジェンダリーの側射・帰還は槍/杖の武技へ、障壁/炎/雷は連携技へ、断罪追撃はQへ接続。

## コードと検証

- `ChainResolver`: Recipe照合、複合属性、命中痕。
- `WeaponActionResolver`: 7武器の技、段階発動、通常命中の帰属、ゲージ、旧祝福移行。
- `CombatChain`: 通常攻撃実行。上記Resolverを共用。
- `tests/skill_runner.gd`: 実際の敵・飛翔体・装備変更・ディスク再開で検証。Visual smoke CIに追加。
- 旧Q/E/Rを前提としたテストは新しい操作契約へ更新。装備効果・帰還・雷撃・契約など既存の回帰検証を維持。

次段階の鍛冶素材確認、自動分解ルール、誓印リスペック、追加ボス、ルート生成、数百Runのバランステレメトリは本変更には含めない。倍率は初期値で、長期バランスが確定したことは意味しない。
